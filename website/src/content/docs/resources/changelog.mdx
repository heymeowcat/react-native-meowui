## 0.4.0 — 2026-10-31

Mochi Press: a tactile, soft-retro visual rebuild on the same zero-dependency
engine.

- New palette and type scale: oat-cream paper, espresso ink, blueberry primary,
  Fraunces / DM Sans / DM Mono, retuned radii, metrics and motion.
- New `theme.fonts` display and mono slots; `Text` resolves display variants
  and `overline`/`mono` through their own voices.
- Warm 2px paper `cast` under controls and cards; blurred `softElevation` for
  floating layers only. Keys shift down 1px and collapse the cast on press.
- Surface, Card, IconButton, Chip, Badge, FAB and ProgressBar refreshed;
  ProgressBar gained the `progressbar` accessibility role and value.
- Four-screen Expo showcase and the full documentation site rebuilt around
  Mochi Press.

## 0.3.0 — 2026-10-27

The ground-up redesign: same package, new engine and visual language.

- **Zero runtime dependencies** — Reanimated, Gesture Handler and all Expo
  peers removed; no Babel plugin.
- Token-based theme system with a semantic color grammar and tuned light/dark
  palettes.
- Calm professional design language: hairline borders, restrained radii, one
  accent, quiet motion.
- 40+ components, typed end to end, with accessibility roles wired through.
- Portal system with zIndex-token stacking; imperative Toast API.
- 2026 toolchain: strict TS 5.9, dual CJS/ESM, ESLint 10, Jest 30 + Testing
  Library, GitHub Actions CI.
