MeowUI ships 40+ components. They all follow the same conventions: sizes are
`'sm' | 'md' | 'lg'` resolved through `theme.metrics`, colorful intent comes
from the `Tone` union (`'primary' | 'success' | 'warning' | 'error' | 'info'`),
and every interactive component is built on the same `Pressable` foundation.

## Conventions you can rely on

- **Sizes**: `'sm' | 'md' | 'lg'` everywhere, driven by `theme.metrics`.
- **Tones**: one union for intent, resolved against `theme.colors`.
- **Icons**: pass any element to `icon` props, or register a renderer for the
  `Icon` adapter — see [Icons](/concepts/icons/).
- **Press feedback**: mechanical — the key shifts down 1px, framed keys scale
  slightly, and the 2px warm cast collapses; flat elements tint instead.
- **Depth**: in-flow surfaces sit on a warm paper `cast`; floating layers use
  the blurred `softElevation`. Neither needs a runtime dependency.
- **Disabled states**: muted colors, no cast, not opacity hacks on colored fills.
- **Portals**: floating components stack by `theme.zIndex` — see
  [Portals & overlays](/concepts/portals/).
